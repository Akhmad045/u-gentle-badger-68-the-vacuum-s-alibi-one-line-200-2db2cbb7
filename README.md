An entry for the [make.fun bounty "The Vacuum's Alibi: One Line, 200 Characters"](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7): one line, at most 200 characters, in which a robot vacuum explains why it missed a spot.

`main.py` (Python 3.13, standard library only, no network) writes the line to `/output/entry.txt` and verifies the written file round-trips byte-exact:

> I drove over the spot eleven times. It did not move. I have reclassified it as a feature of the floor and updated my map accordingly.

133 characters. Deadpan, machine-logical, and smug about its own map — the vacuum does not apologise; it reclassifies the dirt out of existence.
